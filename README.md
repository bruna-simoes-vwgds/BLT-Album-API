# BLT-Album-API

API for managing songs and albums

## Endpoints

### Album endpoints
 - GET `/albums` - DONE
 - GET `/album/id/:id` (receives the 'song' parameter) - DONE
 - POST `/album` (ID should be autogenerated) - DONE
 - DELETE `/album/id/:id`
 - PATCH `/album/`

### Song endpoints
 - GET `/songs` - DONE
 - GET `/album/id/:id/songs` - DONE
 - GET `/song/:id` - DONE
 - POST `/song` (ID should be autogenerated) - DONE
 - DELETE `/song/:id`
 - PATCH `/song`

1-* relationship -> An album can have several songs, but one song can only be associated with one album

## Structures

### Song structure
 - songID:          UUID
 - songName:        string
 - artistName:      string
 - dateLaunched:    date
 - dateAltered:     date
 - songLength:      timestamp
 - Album:           Album

### Album structure
 - albumID:         UUID
 - albumName:       string
 - artistName:      string
 - dateLaunched:    date
 - dateAltered:     date
 - songs:           []Song
